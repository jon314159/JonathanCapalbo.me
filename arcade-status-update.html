Project status update

From Jonathan Capalbo, project coordinator
For the arcade operations manager

Decision needed before test setup: Which time zone should the arcade use to count tickets closed during a reporting period?

Decision owner

The operations manager reviews the closure-reporting requirement (REQ-09). It defines which tickets count as closed and leaves the location’s time zone open. Please confirm the time zone that shift leads use for the daily close.

What depends on the decision

The planned period-boundary test (UAT-13) uses four ticket closures. For a Monday report, a ticket closed at midnight as Monday begins should count. One closed at midnight as Tuesday begins belongs in Tuesday’s report. The tester needs the time zone to set all four timestamps. Test execution is pending.

Next action

At the next requirements review, the coordinator will ask the operations manager to confirm the time zone and record it against REQ-09. The tester can then prepare the four records and check which two count for Monday using the cutoff rules in acceptance criterion AC-09.
