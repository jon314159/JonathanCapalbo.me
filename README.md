## Privacy

The ServiceNow material is from a school lab, not NJIT's production registrar platform. It contains no real student records; public screenshots and notes use only corrected or synthetic registrar content.

The public Excel workbook was rebuilt using entirely fictional records and excludes employer-specific products, customer or account data, goals, revenue, compensation information, and actual performance results.
