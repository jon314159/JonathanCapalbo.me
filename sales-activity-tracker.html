The need

Keep routine activity organized without turning the workbook into a maintenance project.

Daily information is harder to review when entries use different wording, required fields are missed, or summaries must be rebuilt by hand. The workbook needed a clear entry process and a compact review layer.

I used one structured log as the source of truth, then connected validation rules, quality checks, summaries, and charts to that log.

Dashboard view

A quick summary without exposing real performance information.

The demonstration dashboard uses fictional records to show activity volume, outcomes, follow-ups, quality alerts, weekly patterns, and outcome mix. There are no targets, revenue figures, product names, or real customer details.

How it works

The log stays editable; the reporting stays formula-driven.

The activity table is the workbook’s source of truth. New fictional rows can be added using the drop-down lists, while summary formulas and charts respond to the same fields.

  • Filters make the log easy to review
  • Validation limits inconsistent category names
  • Duplicate and completeness formulas remain visible
  • Conditional formatting makes exceptions easy to spot
  • Charts use worksheet ranges instead of pasted values
