# JonathanCapalbo.me

Personal portfolio for Jonathan Capalbo, focused on operations, reporting, automation, and business information systems.

## Featured case study

[NJIT Registrar ServiceNow Knowledge Portal](https://jonathancapalbo.me/servicenow-njit-registrar.html) — an academic, school-lab project with a custom self-service portal, 12 knowledge categories, 42 current articles, search, and version-controlled content.

Technical and scope notes are documented in [`case-studies/servicenow-njit-registrar.md`](case-studies/servicenow-njit-registrar.md).

## Privacy

The ServiceNow material is from a school lab, not NJIT's production registrar platform. It contains no real student records; public screenshots and notes use only corrected or synthetic registrar content.
