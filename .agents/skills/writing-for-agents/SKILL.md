# Write instructions for website work

Use this skill for documents an agent follows, including a reference reached from [AGENTS.md](../../../AGENTS.md). Public portfolio copy and résumé prose use their existing guidance.

## Keep authority and routing clear

Identify the existing source of truth before adding a rule. Preserve the user's scope and approved choices. Route to canonical instructions with a pointer that states the distinct task condition and the resource to read. Keep shared requirements in the entry point and branch-specific detail in the relevant reference.

Use one authoritative statement per rule. Reference environment facts such as configuration, scripts, and actual repository layout rather than copying their contents into another manual. Mark workspace-only resources as optional; a standalone clone must remain understandable without them. Include only available dependencies and resolvable links.

In the Website Improvement workspace, retain its approved anti-slop routing, DURING mode, and design direction. When work calls for diagnosis or behavioral testing, point to the existing skills/reference rather than duplicating their procedures.

## Make the workflow reviewable

State the action, the evidence needed to complete it, and what the result establishes. Name concrete completion criteria, such as a failing symptom reproduced and then resolved, references that resolve, or preserved artifacts that match their baseline.

Keep local validation, independent review, publication, and live verification distinct. Preserve authorization conditions, privacy boundaries, source provenance, and uncertainty when shortening a document. A historical review receipt establishes its recorded scope and date; it does not establish the present working tree or authorize another release.

Define ambiguous website terms where they affect decisions. Native Tableau, its static export, and the React companion have different controls and validation boundaries. Preserve exact project naming and workplace, coursework, and fictional-extension distinctions by pointing to existing factual sources.

## Check the edited instructions

Walk through a realistic triggering request and a nearby request that should use other guidance. Verify that another agent can find the necessary files, follow the allowed path, and distinguish complete from incomplete work.

Check relative links, skill frontmatter when applicable, and supporting references. Compare shortened instructions against the original for lost conditions or changed authority. Remove repetitive or unused material only after checking its callers and purpose.
